# NFL Draft Scouting 🏈

An end-to-end web platform designed to filter, analyze, and visualize NFL Combine metrics and college player statistics. 

## Tech Stack
* **Backend:** Python, FastAPI
* **Database:** SQLite
* **Frontend:** HTML, Vanilla JavaScript

## Features
* **Combine Metrics Filtering:** Search and filter prospects based on physical data like the 40-yard dash, vertical jump, and bench press.
* **Player Statistics:** Access and analyze historical college performance data.
* **RESTful API:** Robust endpoints built with FastAPI to query and serve player data efficiently.
* **Interactive Frontend:** A responsive HTML/JS interface for seamless data exploration.
